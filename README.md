# Echo Shooter

A very simple browser game inspired by *Bullet Echo*: a top-down solo shooter played in a dark house. You face 5 bots, and everyone fights everyone.

Open `index.html` in a browser. Nothing needs to be installed.

- **WASD / arrow keys**: move
- **Mouse**: aim. The gun fires on its own when an enemy is in your flashlight beam, or hold the left mouse button.
- **R**: reload · **Q**: heal (1 per round) · **E**: shield (1 per round)
- **Phone**: the left side of the screen moves you, the right side aims, and the buttons are in the bottom-right corner

You only see enemies inside your flashlight beam. Outside it, enemies give themselves away with red footprints and gunshot rings.
