# Echo Shooter

A very simple browser game inspired by *Bullet Echo*: a top-down 3 vs 3 team shooter played in the dark.

Open `index.html` in a browser. Nothing needs to be installed.

- **WASD / arrow keys**: move
- **Mouse**: aim. The gun fires on its own when an enemy is in your sights, or hold the left mouse button.
- **R**: reload
- **Phone**: the left side of the screen moves you, the right side aims

You only see enemies inside your team's flashlight cones. Outside them, enemies give themselves away with red footprints and gunshot rings.
